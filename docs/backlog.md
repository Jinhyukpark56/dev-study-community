## PR 완료 기준

- 변경 목적을 설명할 수 있음
- 직접 확인한 성공·실패 사례와 테스트 결과 기록
- 의미 있는 권한·데이터 변경에는 자동 테스트 포함
- 관련 문서와 실행 방법이 실제 상태와 일치
- 이해가 부족한 부분과 리뷰 질문 명시
- 친구의 참여 범위와 리뷰 주기는 친구와 별도로 협의

## 첫 리뷰 요청 초안

개발 공부 질문·학습 기록 커뮤니티를 만들면서 Java와 Spring Boot를 공부하려고 합니다.
첫 버전은 가입·로그인, 글, 댓글, 태그별 목록으로 잡았습니다.
요구사항 범위와 개발 작업 순서가 적절한지, 처음에 줄이면 좋을 기능이 있는지 검토 부탁드립니다.
기술 선택은 아직 후보 단계이며, 가능한 리뷰 방식과 주기도 함께 상의하고 싶습니다.

이 문구는 초안이며 친구에게 전송하지 않았습니다.
