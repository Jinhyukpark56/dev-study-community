# 설계 초안

상태: 개념 설계. SQL, API 계약과 기술 버전은 아직 확정하지 않았습니다.

## 데이터 관계

| 데이터 | 주요 항목 | 관계 |
| --- | --- | --- |
| 사용자 | ID, email, 비밀번호 해시 | 여러 글과 댓글을 작성 |
| 게시글 | ID, 작성자 ID, 유형, 제목, 본문, 생성·수정 시각 | 사용자 한 명에 속함 |
| 댓글 | ID, 게시글 ID, 작성자 ID, 본문, 생성·수정 시각 | 글 하나와 사용자 한 명에 속함 |
| 태그 | ID, 이름 | 여러 게시글에 연결 |
| 게시글-태그 | 게시글 ID, 태그 ID | 두 값의 조합은 중복 불가 |

email 중복은 데이터베이스의 유일성 제약으로도 막습니다.
게시글-태그는 글 하나가 여러 태그를 갖고 태그 하나가 여러 글에 붙는 관계를 표현합니다.
삭제 시 연관 데이터의 처리와 트랜잭션 경계는 구현 전에 테스트 시나리오와 함께 구체화합니다.

## 게시글 데이터 상세

사용자와 확인한 기본 항목입니다. 데이터베이스의 구체적인 타입과 Java 타입은 구현 단계에서 결정합니다.

| 항목 | 예시 | 목적과 규칙 |
| --- | --- | --- |
| 글 ID | 101 | 글을 고유하게 구분. 제목이 같아도 다른 글이며 수정해도 ID는 유지. 서버 또는 DB에서 생성 |
| 작성자 ID | 7 | 사용자 데이터와 연결. 로그인한 사용자에서 결정하고 클라이언트 입력으로 지정하지 않음 |
| 유형 | QUESTION | 질문 또는 학습 기록. 하나의 목록에 함께 표시 |
| 제목 | Java return이 궁금합니다 | 목록에 표시하는 글 제목 |
| 본문 | 출력과 반환은 어떻게 다른가요? | 상세 화면의 내용 |
| 작성 시각 | 2026-09-08T10:00:00Z | 최초 저장 시 서버에서 기록하고 수정 시에도 유지 |
| 수정 시각 | 2026-09-08T10:05:00Z | 생성 시 작성 시각과 동일하게 설정하고 수정 시 갱신하는 초안 |

현재 최소 인증 Entity에는 닉네임을 추가하지 않습니다. 작성자 표시 이름은 인증·작성자 인가 이후 별도 요구사항으로 결정합니다.
댓글은 게시글 내부의 문자열로 합치지 않고 별도 데이터로 저장해 게시글 ID로 연결합니다.
태그도 별도 연결 데이터로 관리합니다. 예를 들어 게시글 101과 태그 3의 연결은 (101, 3)으로 표현합니다.

### 예시로 보는 관계

- 사용자 7이 게시글 101 작성
- 사용자 8이 게시글 101에 댓글 501 작성
- 댓글 501에는 작성자 ID 8과 게시글 ID 101이 저장됨
- 게시글 101을 삭제하면 댓글 501과 글-태그 연결도 삭제됨
- 사용자 7·8의 계정과 다른 글에서 사용하는 태그는 유지됨

## 첫 화면 구성

- 목록: 글 유형, 제목, 작성자, 작성일, 태그, 페이지 이동
- 상세: 글 내용, 작성자용 수정·삭제, 댓글 목록과 작성, 본인 댓글 수정·삭제
- 작성·수정: 유형, 제목, 본문, 태그 선택
- 인증: 회원가입, 로그인, 로그아웃

시각 디자인은 핵심 API 검증 뒤 진행합니다.

## 구현 전에 결정할 내용

| 항목 | 현재 방향 | 결정 시점 |
| --- | --- | --- |
| 언어와 서버 | Java 21 + Spring Boot 4.1.1 선택 | 최소 서버 실행 검증 |
| 빌드 도구 | Gradle 9.7.1 Wrapper 선택 | 공식 Initializr 생성 버전으로 고정 |
| 데이터베이스 | 관계형 DB, PostgreSQL 또는 MySQL 검토 | 데이터 저장 작업 전 |
| 데이터 접근 | Spring Data JPA 검토, 사용 전에 필요한 SQL도 학습 | 데이터 저장 작업 전 |
| 인증 | 같은 출처의 웹 화면을 전제로 서버 세션 방식 우선 검토 | 인증 구현 전 |
| 배포 | 비용·운영 부담을 확인한 후 선정 | 첫 배포 전 |

처음부터 캐시 서버, 메시지 큐, 여러 서비스로의 분리를 추가하지 않습니다. 측정된 문제나 실제 요구가 생기면 도입 이유와 대안을 기록합니다.
서버 세션을 선택하면 쿠키 설정, CSRF 방어, 로그아웃 무효화도 함께 설계합니다.
